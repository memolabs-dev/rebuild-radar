# Contribuer à Rebuild Radar

Merci de proposer d'abord des améliorations **reproductibles et sourcées**.

1. Vérifiez la [roadmap](https://github.com/memolabs-dev/rebuild-radar/issues/4) et les issues existantes.
2. Fournissez le dépôt officiel, la version ou le commit observé, la date de consultation et une référence publique précise pour toute proposition éditoriale.
3. Conservez les états `declared`, `documented`, `partial`, `unknown` distincts. `verified` nécessite un protocole, un environnement de test, des résultats et des artefacts reproductibles ; une simple capture, README ou activité GitHub ne suffit pas.
4. Ne partagez aucun binaire propriétaire, secret, compte, document personnel ou élément protégé sans autorisation.
5. Pour le code, ouvrez une PR ciblée et lancez `npm run check && npm test`. N'ajoutez pas de score de « remplacement » calculé à partir des stars.

Ce dépôt propose une découverte et une évaluation transparente des alternatives, pas une affirmation de parité fonctionnelle.
